This Rust project is a typing-based game ressembling the Typing Tutor 7 CD-ROM application by Simon & Schuster for Windows 95.

In order to play, you will need to download this Rust project and compile it using 'cargo run'.

Type words that appear on screen before they reach the bottom and they will disappear. For each successful typing of a word the rate of falling increases.

This program is built for Windows 11 hosts, and is untested on any MacOS or Linux targets.
